# Quadratic Equations - Solved Examples

*Essential examples for algebra*

## Example 1: Solving by Factorization

**Problem:**

Solve: $x^2 + 5x + 6 = 0$

**Solution:**

Factor the quadratic expression:

$$x^2 + 5x + 6 = (x + 2)(x + 3) = 0$$

Using zero product property:
- $x + 2 = 0 \Rightarrow x = -2$
- $x + 3 = 0 \Rightarrow x = -3$

**Answer:** x = -2 or x = -3

**Verification:**
- For x = -2: $(-2)^2 + 5(-2) + 6 = 4 - 10 + 6 = 0$ ✓
- For x = -3: $(-3)^2 + 5(-3) + 6 = 9 - 15 + 6 = 0$ ✓

## Example 2: Using Quadratic Formula

**Problem:**

Solve: $2x^2 + 7x + 3 = 0$

**Solution:**

Given equation: $ax^2 + bx + c = 0$

Here: a = 2, b = 7, c = 3

Quadratic formula: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

**Step 1:** Calculate discriminant
$$\Delta = b^2 - 4ac = 7^2 - 4(2)(3) = 49 - 24 = 25$$

**Step 2:** Apply formula
$$x = \frac{-7 \pm \sqrt{25}}{2(2)} = \frac{-7 \pm 5}{4}$$

**Step 3:** Find both roots
$$x_1 = \frac{-7 + 5}{4} = \frac{-2}{4} = -\frac{1}{2}$$

$$x_2 = \frac{-7 - 5}{4} = \frac{-12}{4} = -3$$

**Answer:** $x = -\frac{1}{2}$ or $x = -3$

## Example 3: Nature of Roots Using Discriminant

**Problem:**

Without solving, determine the nature of roots for:
- (a) $x^2 + 6x + 9 = 0$
- (b) $x^2 + 2x + 5 = 0$
- (c) $2x^2 - 7x + 3 = 0$

**Solution:**

Discriminant: $\Delta = b^2 - 4ac$

Rules:
- If Δ > 0: Two distinct real roots
- If Δ = 0: One repeated real root
- If Δ < 0: Two complex roots

**(a)** $x^2 + 6x + 9 = 0$
$$\Delta = 6^2 - 4(1)(9) = 36 - 36 = 0$$
**Nature:** One repeated real root

**(b)** $x^2 + 2x + 5 = 0$
$$\Delta = 2^2 - 4(1)(5) = 4 - 20 = -16 < 0$$
**Nature:** Two complex roots

**(c)** $2x^2 - 7x + 3 = 0$
$$\Delta = (-7)^2 - 4(2)(3) = 49 - 24 = 25 > 0$$
**Nature:** Two distinct real roots

## Example 4: Sum and Product of Roots

**Problem:**

If α and β are roots of $3x^2 - 5x + 2 = 0$, find:
- (i) α + β
- (ii) αβ
- (iii) α² + β²

**Solution:**

For equation $ax^2 + bx + c = 0$:
- Sum of roots: $\alpha + \beta = -\frac{b}{a}$
- Product of roots: $\alpha\beta = \frac{c}{a}$

Here: a = 3, b = -5, c = 2

**(i)** $\alpha + \beta = -\frac{(-5)}{3} = \frac{5}{3}$

**(ii)** $\alpha\beta = \frac{2}{3}$

**(iii)** $\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta$

$$= \left(\frac{5}{3}\right)^2 - 2\left(\frac{2}{3}\right) = \frac{25}{9} - \frac{4}{3}$$

$$= \frac{25}{9} - \frac{12}{9} = \frac{13}{9}$$

## Example 5: Forming Equation from Roots

**Problem:**

Form a quadratic equation whose roots are 3 and -5.

**Solution:**

If α and β are roots, equation is:
$$x^2 - (\alpha + \beta)x + \alpha\beta = 0$$

Here: α = 3, β = -5

Sum: $\alpha + \beta = 3 + (-5) = -2$

Product: $\alpha\beta = (3)(-5) = -15$

**Equation:**
$$x^2 - (-2)x + (-15) = 0$$
$$x^2 + 2x - 15 = 0$$

**Verification by factoring:**
$$x^2 + 2x - 15 = (x - 3)(x + 5) = 0$$
Roots: x = 3 or x = -5 ✓

## Example 6: Completing the Square

**Problem:**

Solve $x^2 + 6x + 2 = 0$ by completing the square.

**Solution:**

**Step 1:** Move constant to right side
$$x^2 + 6x = -2$$

**Step 2:** Add $(b/2)^2$ to both sides where b = 6
$$(6/2)^2 = 9$$

$$x^2 + 6x + 9 = -2 + 9$$

**Step 3:** Factor left side
$$(x + 3)^2 = 7$$

**Step 4:** Take square root
$$x + 3 = \pm\sqrt{7}$$

**Step 5:** Solve for x
$$x = -3 \pm \sqrt{7}$$

**Answer:** $x = -3 + \sqrt{7}$ or $x = -3 - \sqrt{7}$

## Example 7: Word Problem

**Problem:**

The sum of a number and its reciprocal is $\frac{13}{6}$. Find the number.

**Solution:**

Let the number be x.

Its reciprocal = $\frac{1}{x}$

According to problem:
$$x + \frac{1}{x} = \frac{13}{6}$$

Multiply by 6x:
$$6x^2 + 6 = 13x$$

Rearrange:
$$6x^2 - 13x + 6 = 0$$

Using quadratic formula (a = 6, b = -13, c = 6):

$$\Delta = (-13)^2 - 4(6)(6) = 169 - 144 = 25$$

$$x = \frac{13 \pm 5}{12}$$

$$x_1 = \frac{18}{12} = \frac{3}{2}, \quad x_2 = \frac{8}{12} = \frac{2}{3}$$

**Answer:** The number is $\frac{3}{2}$ or $\frac{2}{3}$

**Note:** Both solutions are valid; they are reciprocals of each other.

## Example 8: Maximum/Minimum Value

**Problem:**

Find the minimum value of $f(x) = x^2 - 4x + 7$.

**Solution:**

For a quadratic $ax^2 + bx + c$:
- If a > 0: minimum value at $x = -\frac{b}{2a}$
- If a < 0: maximum value at $x = -\frac{b}{2a}$

Here: a = 1 (> 0), b = -4, c = 7

**Vertex x-coordinate:**
$$x = -\frac{(-4)}{2(1)} = 2$$

**Minimum value:**
$$f(2) = 2^2 - 4(2) + 7 = 4 - 8 + 7 = 3$$

**Answer:** Minimum value is 3 at x = 2

## Key Formulas

### Quadratic Equation
**Standard form:** $ax^2 + bx + c = 0$, where $a \neq 0$

### Quadratic Formula
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

### Discriminant
$$\Delta = b^2 - 4ac$$
- Δ > 0: Two distinct real roots
- Δ = 0: One repeated root
- Δ < 0: Two complex roots

### Sum and Product of Roots
- Sum: $\alpha + \beta = -\frac{b}{a}$
- Product: $\alpha\beta = \frac{c}{a}$

### Equation from Roots
$$x^2 - (\text{sum})x + (\text{product}) = 0$$

### Vertex Form
$$x = -\frac{b}{2a}$$ (x-coordinate of vertex)
