# Quadratic Equations

## Standard Form

A quadratic equation is an equation of the form:

ax² + bx + c = 0

Where:
- a ≠ 0 (if a = 0, it becomes a linear equation)
- a, b, c are real constants
- x is the variable

## Quadratic Formula

The solutions (roots) of ax² + bx + c = 0 are given by:

x = [-b ± √(b² - 4ac)] / (2a)

This gives two roots:
- x₁ = [-b + √(b² - 4ac)] / (2a)
- x₂ = [-b - √(b² - 4ac)] / (2a)

## Discriminant

The discriminant D determines the nature of roots:

D = b² - 4ac

Nature of roots:
- If D > 0: Two distinct real roots
- If D = 0: Two equal real roots (repeated root)
- If D < 0: Two complex conjugate roots (no real roots)

## Sum and Product of Roots

For the equation ax² + bx + c = 0 with roots α and β:

Sum of roots: α + β = -b/a

Product of roots: α × β = c/a

## Forming Quadratic Equation from Roots

If α and β are the roots, the equation is:

x² - (α + β)x + (αβ) = 0

Or in general form:

x² - (sum of roots)x + (product of roots) = 0

## Properties of Roots

### Common Root

If ax² + bx + c = 0 and px² + qx + r = 0 have a common root α, then:

(ar - cp)² = (aq - bp)(br - cq)

### Both Roots Common

If both roots are common:

a/p = b/q = c/r

## Maximum and Minimum Values

For quadratic expression f(x) = ax² + bx + c:

- If a > 0: Minimum value = (4ac - b²)/(4a) at x = -b/(2a)
- If a < 0: Maximum value = (4ac - b²)/(4a) at x = -b/(2a)

## Sign of Quadratic Expression

For f(x) = ax² + bx + c:

### When a > 0 (parabola opens upward):
- f(x) > 0 for all x if D < 0
- f(x) ≥ 0 for all x if D = 0
- f(x) > 0 except between roots if D > 0

### When a < 0 (parabola opens downward):
- f(x) < 0 for all x if D < 0
- f(x) ≤ 0 for all x if D = 0
- f(x) < 0 except between roots if D > 0

## Location of Roots

Let α and β be roots of ax² + bx + c = 0.

### Both roots greater than k:
- D ≥ 0
- -b/(2a) > k
- af(k) > 0

### Both roots less than k:
- D ≥ 0
- -b/(2a) < k
- af(k) > 0

### Roots on opposite sides of k:
- af(k) < 0

### Both roots in interval (k₁, k₂):
- D ≥ 0
- k₁ < -b/(2a) < k₂
- af(k₁) > 0 and af(k₂) > 0

## Important Special Cases

### Perfect Square
ax² + bx + c is a perfect square if D = 0

### Sum of Two Squares
x² + y² = k can be written as (x + iy)(x - iy) = k

## Common Formulas

If α, β are roots of x² + px + q = 0:

- α² + β² = (α + β)² - 2αβ = p² - 2q
- α³ + β³ = (α + β)³ - 3αβ(α + β) = -p³ + 3pq
- α⁴ + β⁴ = (α² + β²)² - 2(αβ)² = (p² - 2q)² - 2q²
- |α - β| = √(α + β)² - 4αβ = √(p² - 4q)
- 1/α + 1/β = (α + β)/(αβ) = -p/q

## Theory of Equations

For cubic and higher degree equations, use:

### Relation between roots and coefficients:
For equation xⁿ + a₁xⁿ⁻¹ + a₂xⁿ⁻² + ... + aₙ = 0 with roots α₁, α₂, ..., αₙ:

- Sum of roots = -a₁
- Sum of products of roots taken two at a time = a₂
- Sum of products of roots taken three at a time = -a₃
- Product of all roots = (-1)ⁿ × aₙ
