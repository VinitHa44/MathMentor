## Problem 1: Distance Between Points
**Question:** Find distance between (1, 2, 3) and (4, 6, 8)

**Solution:**
d = √[(4-1)² + (6-2)² + (8-3)²]
= √[9 + 16 + 25]
= √50 = 5√2

**Answer:** 5√2

## Problem 2: Section Formula
**Question:** Find point dividing line from (2, 3, 4) to (6, 7, 8) in ratio 3:1

**Solution:**
x = (3×6 + 1×2)/(3+1) = 20/4 = 5
y = (3×7 + 1×3)/(3+1) = 24/4 = 6
z = (3×8 + 1×4)/(3+1) = 28/4 = 7

## Problem 5: Angle Between Lines
**Question:** Find angle between lines with direction ratios (1, 2, 2) and (2, 3, 6)

**Solution:**
cos(θ) = (a₁a₂ + b₁b₂ + c₁c₂)/[√(a₁²+b₁²+c₁²)·√(a₂²+b₂²+c₂²)]

= (2 + 6 + 12)/[√9·√49]
= 20/(3×7) = 20/21

θ = cos⁻¹(20/21)

**Answer:** cos⁻¹(20/21)

## Problem 12: Shortest Distance Between Skew Lines
**Question:** Find shortest distance between lines:
**r** = **i** + 2**j** + 3**k** + λ(**i** + **j** + **k**)
**r** = 2**i** + 3**j** + **k** + μ(2**i** + 3**j** + 4**k**)

**Solution:**
**a₁** = **i** + 2**j** + 3**k**, **b₁** = **i** + **j** + **k**
**a₂** = 2**i** + 3**j** + **k**, **b₂** = 2**i** + 3**j** + 4**k**

**a₂** - **a₁** = **i** + **j** - 2**k**
**b₁** × **b₂** = **i** + 2**j** - **k**

d = |(**a₂**-**a₁**)·(**b₁**×**b₂**)|/|**b₁**×**b₂**|
= |1 + 2 + 2|/√(1 + 4 + 1)
= 5/√6

**Answer:** 5/√6

## Problem 15: Foot of Perpendicular
**Question:** Find foot of perpendicular from (1, 2, 3) to plane x + y + z = 6

**Solution:**
Line through (1, 2, 3) perpendicular to plane:
(x-1)/1 = (y-2)/1 = (z-3)/1 = k

x = 1+k, y = 2+k, z = 3+k

Substitute in plane:
(1+k) + (2+k) + (3+k) = 6
6 + 3k = 6
k = 0

Foot: (1, 2, 3)

Actually (1,2,3) is ON the plane (1+2+3=6)

**Answer:** (1, 2, 3) itself

## Problem 19: Image of Point
**Question:** Find image of (1, 2, 3) in plane x + y + z = 9

**Solution:**
Perpendicular from point:
(x-1)/1 = (y-2)/1 = (z-3)/1 = k

Point on line: (1+k, 2+k, 3+k)
On plane: (1+k) + (2+k) + (3+k) = 9
6 + 3k = 9, k = 1

Foot: (2, 3, 4)

Image: (2×2-1, 2×3-2, 2×4-3) = (3, 4, 5)

**Answer:** (3, 4, 5)
