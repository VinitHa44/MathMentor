# Practice Problems: Trigonometry (20 Problems)

## Problem 1: Basic Identity
**Question:** If sin(θ) = 3/5 and θ is acute, find cos(θ)

**Solution:**
sin²(θ) + cos²(θ) = 1
(3/5)² + cos²(θ) = 1
cos²(θ) = 1 - 9/25 = 16/25
cos(θ) = 4/5 (positive in 1st quadrant)

**Answer:** 4/5

## Problem 2: Compound Angle
**Question:** Find sin(75°)

**Solution:**
sin(75°) = sin(45° + 30°)
= sin(45°)cos(30°) + cos(45°)sin(30°)
= (1/√2)(√3/2) + (1/√2)(1/2)
= (√3 + 1)/(2√2)
= (√3 + 1)√2/4
= (√6 + √2)/4

**Answer:** (√6 + √2)/4

## Problem 3: Double Angle
**Question:** If tan(θ) = 3/4, find sin(2θ)

**Solution:**
sin(2θ) = 2tan(θ)/(1 + tan²(θ))
= 2(3/4)/(1 + 9/16)
= (3/2)/(25/16)
= (3/2)(16/25)
= 24/25

**Answer:** 24/25

## Problem 9: Conditional Identity
**Question:** If A + B + C = π, prove tan(A) + tan(B) + tan(C) = tan(A)tan(B)tan(C)

**Solution:**
A + B = π - C
tan(A + B) = tan(π - C) = -tan(C)

[tan(A) + tan(B)]/[1 - tan(A)tan(B)] = -tan(C)

tan(A) + tan(B) = -tan(C)[1 - tan(A)tan(B)]
tan(A) + tan(B) = -tan(C) + tan(A)tan(B)tan(C)

tan(A) + tan(B) + tan(C) = tan(A)tan(B)tan(C)

**Answer:** Proven

## Problem 10: Sine Rule
**Question:** In triangle ABC, a = 7, b = 8, A = 30°. Find sin(B)

**Solution:**
a/sin(A) = b/sin(B)
7/sin(30°) = 8/sin(B)
7/(1/2) = 8/sin(B)
14 = 8/sin(B)

**Answer:** 4/7

## Problem 12: Half Angle
**Question:** If cos(θ) = 1/3, find cos(θ/2) for 0 < θ < π

**Solution:**
cos(θ/2) = ±√[(1 + cos(θ))/2]
= ±√[(1 + 1/3)/2]
= ±√[4/6]
= ±√(2/3)

Since 0 < θ < π, 0 < θ/2 < π/2
cos(θ/2) is positive

= √(2/3) = √6/3

**Answer:** √6/3

## Problem 16: Trigonometric Equation
**Question:** Solve 2cos²(x) - 3sin(x) - 3 = 0 for 0 ≤ x ≤ 2π

**Solution:**
2(1 - sin²(x)) - 3sin(x) - 3 = 0
2 - 2sin²(x) - 3sin(x) - 3 = 0
-2sin²(x) - 3sin(x) - 1 = 0
2sin²(x) + 3sin(x) + 1 = 0
(2sin(x) + 1)(sin(x) + 1) = 0

sin(x) = -1/2 or sin(x) = -1

x = 7π/6, 11π/6 or x = 3π/2

**Answer:** x = 7π/6, 3π/2, 11π/6

**Solution:**

= 24 × (1/2)

## Problem 18: Multiple Angles
**Question:** Prove cos(4θ) = 8cos⁴(θ) - 8cos²(θ) + 1

**Solution:**
cos(4θ) = cos(2×2θ)
= 2cos²(2θ) - 1
= 2[2cos²(θ) - 1]² - 1
= 2[4cos⁴(θ) - 4cos²(θ) + 1] - 1
= 8cos⁴(θ) - 8cos²(θ) + 2 - 1
= 8cos⁴(θ) - 8cos²(θ) + 1

**Answer:** Proven

## Problem 19: Tan Addition
**Question:** If tan(A) = 1/2 and tan(B) = 1/3, find tan(A + B)

**Solution:**
tan(A + B) = [tan(A) + tan(B)]/[1 - tan(A)tan(B)]
= [1/2 + 1/3]/[1 - (1/2)(1/3)]
= [5/6]/[1 - 1/6]
= [5/6]/[5/6]
= 1

**Answer:** 1

## Problem 20: Height and Distance
**Question:** From top of 100m tower, angles of depression to two points on ground (same side) are 30° and 45°. Find distance between points.

**Solution:**
Let tower height = 100m

For 45° angle:
tan(45°) = 100/d₁
d₁ = 100m

For 30° angle:
tan(30°) = 100/d₂
1/√3 = 100/d₂
d₂ = 100√3m

Distance = d₂ - d₁ = 100√3 - 100 = 100(√3 - 1)m

**Answer:** 100(√3 - 1)m ≈ 73.2m
