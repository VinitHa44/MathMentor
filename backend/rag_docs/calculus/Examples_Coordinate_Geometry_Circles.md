# Practice Problems: Circles (20 Problems)

## Problem 1: Standard Equation
**Question:** Find equation of circle with center (3, -2) and radius 5

**Solution:**
(x - h)² + (y - k)² = r²
(x - 3)² + (y + 2)² = 25

**Answer:** (x - 3)² + (y + 2)² = 25

---

## Problem 2: General Form to Standard
**Question:** Find center and radius of x² + y² - 6x + 4y - 12 = 0

**Solution:**
Compare with x² + y² + 2gx + 2fy + c = 0

2g = -6 → g = -3
2f = 4 → f = 2
c = -12

Center: (-g, -f) = (3, -2)
Radius: √(g² + f² - c) = √(9 + 4 + 12) = √25 = 5

**Answer:** Center (3, -2), Radius 5

---

## Problem 3: Diameter Form
**Question:** Find equation of circle with diameter endpoints (2, 3) and (6, 7)

**Solution:**
(x - x₁)(x - x₂) + (y - y₁)(y - y₂) = 0
(x - 2)(x - 6) + (y - 3)(y - 7) = 0
x² - 8x + 12 + y² - 10y + 21 = 0
x² + y² - 8x - 10y + 33 = 0

**Answer:** x² + y² - 8x - 10y + 33 = 0

---

## Problem 4: Position of Point
**Question:** Check if point (2, 1) lies inside, on, or outside circle x² + y² = 10

**Solution:**
S₁ = 2² + 1² - 10 = 4 + 1 - 10 = -5

S₁ < 0 → inside circle

**Answer:** Inside

---

## Problem 5: Tangent at Point
**Question:** Find equation of tangent to circle x² + y² = 25 at point (3, 4)

**Solution:**
xx₁ + yy₁ = r²
3x + 4y = 25

**Answer:** 3x + 4y = 25

---

## Problem 6: Tangent with Slope
**Question:** Find equation of tangent to x² + y² = 25 with slope -3/4

**Solution:**
y = mx ± r√(1 + m²)
y = (-3/4)x ± 5√(1 + 9/16)
y = (-3/4)x ± 5√(25/16)
y = (-3/4)x ± 25/4

4y = -3x ± 25
3x + 4y ± 25 = 0

**Answer:** 3x + 4y + 25 = 0 and 3x + 4y - 25 = 0

---

## Problem 7: Length of Tangent
**Question:** Find length of tangent from point (7, 1) to circle x² + y² = 25

**Solution:**
L = √(x₁² + y₁² - r²)
= √(49 + 1 - 25)
= √25 = 5

**Answer:** 5

## Problem 8: Chord of Contact
**Question:** Find chord of contact from external point (5, 0) to circle x² + y² = 9

**Solution:**
xx₁ + yy₁ = r²
5x + 0y = 9
5x = 9

**Answer:** 5x = 9

## Problem 9: Parametric Form
**Question:** Find point on circle x² + y² = 16 at parameter θ = π/4

**Solution:**
x = r·cos(θ) = 4·cos(π/4) = 4/√2 = 2√2
y = r·sin(θ) = 4·sin(π/4) = 4/√2 = 2√2

**Answer:** (2√2, 2√2)

## Problem 10: Normal Equation
**Question:** Find equation of normal to x² + y² = 25 at point (3, 4)

**Solution:**
Normal passes through center (0, 0) and point (3, 4)

Slope = 4/3
Equation: y = (4/3)x
Or: 4x - 3y = 0

**Answer:** 4x - 3y = 0

## Problem 11: Circle Through Three Points
**Question:** Find equation of circle passing through (0, 0), (4, 0), (0, 3)

**Solution:**
General: x² + y² + 2gx + 2fy + c = 0

Point (0,0): c = 0
Point (4,0): 16 + 8g = 0 → g = -2
Point (0,3): 9 + 6f = 0 → f = -3/2

Equation: x² + y² - 4x - 3y = 0

**Answer:** x² + y² - 4x - 3y = 0

---

## Problem 12: Radical Axis
**Question:** Find radical axis of circles x² + y² - 4x - 2y + 1 = 0 and x² + y² - 2x - 4y - 4 = 0

**Solution:**
S₁ - S₂ = 0
(x² + y² - 4x - 2y + 1) - (x² + y² - 2x - 4y - 4) = 0
-4x + 2x - 2y + 4y + 1 + 4 = 0
-2x + 2y + 5 = 0
2x - 2y - 5 = 0

**Answer:** 2x - 2y - 5 = 0

---

## Problem 13: Orthogonal Circles
**Question:** Check if circles x² + y² = 4 and x² + y² - 4x - 4y + 4 = 0 are orthogonal

**Solution:**
For orthogonality: 2g₁g₂ + 2f₁f₂ = c₁ + c₂

Circle 1: g₁ = 0, f₁ = 0, c₁ = -4
Circle 2: g₂ = -2, f₂ = -2, c₂ = 4

Check: 2(0)(-2) + 2(0)(-2) = -4 + 4
0 = 0 ✓

**Answer:** Yes, orthogonal

---

## Problem 14: Director Circle
**Question:** Find director circle of x² + y² = 9

**Solution:**
Director circle: x² + y² = 2r²
= 2(9)
= 18

**Answer:** x² + y² = 18

## Problem 15: Power of Point
**Question:** Find power of point (4, 5) with respect to circle x² + y² = 9

**Solution:**
Power = x₁² + y₁² - r²
= 16 + 25 - 9
= 32

**Answer:** 32

## Problem 16: Common Tangents
**Question:** Find number of common tangents to circles x² + y² = 4 and (x-6)² + y² = 9

**Solution:**
Centers: (0,0) and (6,0)
Radii: r₁ = 2, r₂ = 3
Distance: d = 6

Since d > r₁ + r₂ (6 > 5): 4 common tangents

**Answer:** 4

---

## Problem 17: Family of Circles
**Question:** Find equation of circle through intersection of x² + y² = 25 and line x + y = 7

**Solution:**
Family: x² + y² - 25 + λ(x + y - 7) = 0

For specific circle, need additional condition

**Answer:** x² + y² + λx + λy - (25 + 7λ) = 0

## Problem 18: Chord with Midpoint
**Question:** Find equation of chord of x² + y² = 25 with midpoint (2, 3)

**Solution:**
T = S₁

xx₁ + yy₁ - r² = x₁² + y₁² - r²
2x + 3y - 25 = 4 + 9 - 25
2x + 3y = -12 + 25
2x + 3y = 13

**Answer:** 2x + 3y = 13

---

## Problem 19: Limiting Points
**Question:** Find limiting points of coaxal system x² + y² + 2x + λy + 1 = 0

**Solution:**
For limiting points, both equations and their difference = 0

From radical axis: y = 0
Substitute: x² + 2x + 1 = 0
(x + 1)² = 0
x = -1

**Answer:** (-1, 0)

---

## Problem 20: Circle Touching Both Axes
**Question:** Find equation of circle with radius 5 touching both coordinate axes

**Solution:**
If touching both axes, center is (±5, ±5)

Four circles:
(x - 5)² + (y - 5)² = 25
(x + 5)² + (y - 5)² = 25
(x - 5)² + (y + 5)² = 25
(x + 5)² + (y + 5)² = 25

**Answer:** (x ± 5)² + (y ± 5)² = 25
