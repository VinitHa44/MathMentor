# Trigonometry - Basics and Identities

## Basic Trigonometric Ratios

In a right triangle with angle θ:

sin(θ) = Opposite/Hypotenuse
cos(θ) = Adjacent/Hypotenuse
tan(θ) = Opposite/Adjacent
cot(θ) = Adjacent/Opposite
sec(θ) = Hypotenuse/Adjacent
cosec(θ) = Hypotenuse/Opposite

## Reciprocal Identities

sin(θ) = 1/cosec(θ)
cos(θ) = 1/sec(θ)
tan(θ) = 1/cot(θ)
cot(θ) = 1/tan(θ)
sec(θ) = 1/cos(θ)
cosec(θ) = 1/sin(θ)

## Quotient Identities

tan(θ) = sin(θ)/cos(θ)
cot(θ) = cos(θ)/sin(θ)

## Pythagorean Identities

sin²(θ) + cos²(θ) = 1

1 + tan²(θ) = sec²(θ)

1 + cot²(θ) = cosec²(θ)

## Values of Trigonometric Functions

### For standard angles (in degrees):

| Angle | 0° | 30° | 45° | 60° | 90° |
|-------|-----|-----|-----|-----|-----|
| sin   | 0   | 1/2 | 1/√2| √3/2| 1   |
| cos   | 1   | √3/2| 1/√2| 1/2 | 0   |
| tan   | 0   | 1/√3| 1   | √3  | ∞   |

### In radians:
0° = 0, 30° = π/6, 45° = π/4, 60° = π/3, 90° = π/2

## Allied Angles (Reduction Formulas)

### Negative angles:
sin(-θ) = -sin(θ)
cos(-θ) = cos(θ)
tan(-θ) = -tan(θ)

### Complementary angles (90° - θ):
sin(90° - θ) = cos(θ)
cos(90° - θ) = sin(θ)
tan(90° - θ) = cot(θ)
cot(90° - θ) = tan(θ)
sec(90° - θ) = cosec(θ)
cosec(90° - θ) = sec(θ)

### Supplementary angles (180° - θ):
sin(180° - θ) = sin(θ)
cos(180° - θ) = -cos(θ)
tan(180° - θ) = -tan(θ)

### 180° + θ:
sin(180° + θ) = -sin(θ)
cos(180° + θ) = -cos(θ)
tan(180° + θ) = tan(θ)

### 360° - θ:
sin(360° - θ) = -sin(θ)
cos(360° - θ) = cos(θ)
tan(360° - θ) = -tan(θ)

## Sum and Difference Formulas

sin(A + B) = sin(A)cos(B) + cos(A)sin(B)
sin(A - B) = sin(A)cos(B) - cos(A)sin(B)

cos(A + B) = cos(A)cos(B) - sin(A)sin(B)
cos(A - B) = cos(A)cos(B) + sin(A)sin(B)

tan(A + B) = [tan(A) + tan(B)] / [1 - tan(A)tan(B)]
tan(A - B) = [tan(A) - tan(B)] / [1 + tan(A)tan(B)]

cot(A + B) = [cot(A)cot(B) - 1] / [cot(A) + cot(B)]
cot(A - B) = [cot(A)cot(B) + 1] / [cot(B) - cot(A)]

## Double Angle Formulas

sin(2A) = 2sin(A)cos(A) = 2tan(A)/(1 + tan²(A))

cos(2A) = cos²(A) - sin²(A)
        = 2cos²(A) - 1
        = 1 - 2sin²(A)
        = (1 - tan²(A))/(1 + tan²(A))

tan(2A) = 2tan(A) / (1 - tan²(A))

## Triple Angle Formulas

sin(3A) = 3sin(A) - 4sin³(A)

cos(3A) = 4cos³(A) - 3cos(A)

tan(3A) = [3tan(A) - tan³(A)] / [1 - 3tan²(A)]

## Half Angle Formulas

sin(A/2) = ±√[(1 - cos(A))/2]

cos(A/2) = ±√[(1 + cos(A))/2]

tan(A/2) = ±√[(1 - cos(A))/(1 + cos(A))]
         = sin(A)/(1 + cos(A))
         = (1 - cos(A))/sin(A)

## Product to Sum Formulas

2sin(A)cos(B) = sin(A + B) + sin(A - B)

2cos(A)cos(B) = cos(A + B) + cos(A - B)

2sin(A)sin(B) = cos(A - B) - cos(A + B)

## Sum to Product Formulas

sin(A) + sin(B) = 2sin[(A+B)/2]cos[(A-B)/2]

sin(A) - sin(B) = 2cos[(A+B)/2]sin[(A-B)/2]

cos(A) + cos(B) = 2cos[(A+B)/2]cos[(A-B)/2]

cos(A) - cos(B) = -2sin[(A+B)/2]sin[(A-B)/2]

## Important Identities

sin²(A) = (1 - cos(2A))/2

cos²(A) = (1 + cos(2A))/2

sin³(A) = [3sin(A) - sin(3A)]/4

cos³(A) = [3cos(A) + cos(3A)]/4

## Conditional Identities

If A + B + C = π (or 180°):

sin(A) + sin(B) + sin(C) = 4cos(A/2)cos(B/2)cos(C/2)

cos(A) + cos(B) + cos(C) = 1 + 4sin(A/2)sin(B/2)sin(C/2)

tan(A) + tan(B) + tan(C) = tan(A)tan(B)tan(C)

If A + B + C = π/2:

tan(A)tan(B) + tan(B)tan(C) + tan(C)tan(A) = 1

Maximum = √(a² + b²)
Minimum = -√(a² + b²)

## Trigonometric Equations

### sin(θ) = sin(α)
General solution: θ = nπ + (-1)ⁿα, where n ∈ Z

### cos(θ) = cos(α)
General solution: θ = 2nπ ± α, where n ∈ Z

### tan(θ) = tan(α)
General solution: θ = nπ + α, where n ∈ Z

### Special Cases:
sin(θ) = 0: θ = nπ
cos(θ) = 0: θ = (2n+1)π/2
tan(θ) = 0: θ = nπ

sin(θ) = 1: θ = (4n+1)π/2
sin(θ) = -1: θ = (4n-1)π/2
cos(θ) = 1: θ = 2nπ
cos(θ) = -1: θ = (2n+1)π

## Sine and Cosine Rules

### For any triangle ABC:

**Sine Rule:**
a/sin(A) = b/sin(B) = c/sin(C) = 2R

Where R is circumradius

**Cosine Rule:**
a² = b² + c² - 2bc·cos(A)
b² = a² + c² - 2ac·cos(B)
c² = a² + b² - 2ab·cos(C)

**Projection Formula:**
a = b·cos(C) + c·cos(B)
b = a·cos(C) + c·cos(A)
c = a·cos(B) + b·cos(A)

## Area of Triangle

Area = (1/2)bc·sin(A) = (1/2)ac·sin(B) = (1/2)ab·sin(C)

Area = √[s(s-a)(s-b)(s-c)] (Heron's formula)

Where s = (a+b+c)/2

Area = abc/(4R) where R is circumradius

Area = rs where r is inradius

## Common Mistakes to Avoid

- Confusing degrees and radians
- Wrong signs in quadrants
- Incorrect use of principal values
- Not checking domain of inverse functions
- Sign errors in reduction formulas
- Forgetting periodicity in general solutions
