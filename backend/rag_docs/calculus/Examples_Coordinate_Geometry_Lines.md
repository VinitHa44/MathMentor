# Practice Problems: Straight Lines (20 Problems)

## Problem 1: Distance Formula
**Question:** Find distance between points (3, 4) and (7, 1)

**Solution:**
d = √[(7-3)² + (1-4)²]
= √[16 + 9]
= √25 = 5

**Answer:** 5

## Problem 2: Slope
**Question:** Find slope of line joining (2, 3) and (5, 11)

**Solution:**
m = (y₂ - y₁)/(x₂ - x₁)
= (11 - 3)/(5 - 2)
= 8/3

**Answer:** 8/3

---

## Problem 3: Midpoint
**Question:** Find midpoint of line segment joining (-2, 3) and (4, -1)

**Solution:**
Midpoint = ((x₁+x₂)/2, (y₁+y₂)/2)
= ((-2+4)/2, (3-1)/2)
= (1, 1)

**Answer:** (1, 1)

---

## Problem 4: Equation of Line
**Question:** Find equation of line with slope 2 passing through (3, -1)

**Solution:**
y - y₁ = m(x - x₁)
y - (-1) = 2(x - 3)
y + 1 = 2x - 6
2x - y - 7 = 0

**Answer:** 2x - y - 7 = 0

## Problem 5: Parallel Lines
**Question:** Find equation of line parallel to 3x + 4y = 12 passing through (1, 2)

**Solution:**
Parallel line has same slope: -3/4

Using point-slope form:
3x + 4y = k

Substitute (1, 2):
3(1) + 4(2) = k
k = 11

Equation: 3x + 4y = 11

**Answer:** 3x + 4y = 11

## Problem 6: Perpendicular Lines
**Question:** Find slope of line perpendicular to line with slope 2/3

**Solution:**
m₁ × m₂ = -1
(2/3) × m₂ = -1
m₂ = -3/2

**Answer:** -3/2

## Problem 8: Angle Between Lines
**Question:** Find acute angle between lines x + y = 1 and x - y = 1

**Solution:**
Slopes: m₁ = -1, m₂ = 1

tan(θ) = |m₁ - m₂|/|1 + m₁m₂|
= |-1 - 1|/|1 + (-1)(1)|
= 2/0 → undefined

Lines are perpendicular
θ = 90°

**Answer:** 90°

## Problem 10: Section Formula
**Question:** Find point dividing line from (2, 3) to (5, 9) in ratio 2:1 internally

**Solution:**
x = (mx₂ + nx₁)/(m+n) = (2×5 + 1×2)/(2+1) = 12/3 = 4
y = (my₂ + ny₁)/(m+n) = (2×9 + 1×3)/(2+1) = 21/3 = 7

**Answer:** (4, 7)

## Problem 11: Collinearity
**Question:** Check if points (1, 2), (3, 6), (5, 10) are collinear

**Solution:**
Slope between (1,2) and (3,6): (6-2)/(3-1) = 4/2 = 2
Slope between (3,6) and (5,10): (10-6)/(5-3) = 4/2 = 2

Slopes are equal → collinear

**Answer:** Yes, collinear

## Problem 12: Family of Lines
**Question:** Find equation of line through intersection of x + y = 1 and 2x - y = 5 passing through origin

**Solution:**
Family: (x + y - 1) + λ(2x - y - 5) = 0

For origin (0,0):
(-1) + λ(-5) = 0
λ = -1/5

Equation: (x + y - 1) - (1/5)(2x - y - 5) = 0
5(x + y - 1) - (2x - y - 5) = 0
5x + 5y - 5 - 2x + y + 5 = 0
3x + 6y = 0
x + 2y = 0

**Answer:** x + 2y = 0

## Problem 14: Area of Triangle
**Question:** Find area of triangle with vertices (0, 0), (4, 0), (2, 3)

**Solution:**
Area = (1/2)|x₁(y₂ - y₃) + x₂(y₃ - y₁) + x₃(y₁ - y₂)|
= (1/2)|0(0 - 3) + 4(3 - 0) + 2(0 - 0)|
= (1/2)|0 + 12 + 0|
= 6

**Answer:** 6

## Problem 15: Angle Bisectors
**Question:** Find bisector of angle between x + 2y - 5 = 0 and 2x + y - 7 = 0

**Solution:**
Bisectors:
(x + 2y - 5)/√(1² + 2²) = ±(2x + y - 7)/√(2² + 1²)

(x + 2y - 5)/√5 = ±(2x + y - 7)/√5

x + 2y - 5 = ±(2x + y - 7)

Bisector 1: x + 2y - 5 = 2x + y - 7
-x + y + 2 = 0
x - y - 2 = 0

Bisector 2: x + 2y - 5 = -(2x + y - 7)
3x + 3y - 12 = 0
x + y - 4 = 0

**Answer:** x - y - 2 = 0 and x + y - 4 = 0

## Problem 16: Reflection
**Question:** Find image of point (3, 4) in line x + y = 0

**Solution:**
Using reflection formula:
(x' - 3)/1 = (y' - 4)/1 = -2(3 + 4)/(1² + 1²)
= -14/2 = -7

x' = 3 - 7 = -4
y' = 4 - 7 = -3

**Answer:** (-4, -3)

## Problem 17: Centroid
**Question:** Find centroid of triangle with vertices (2, 3), (4, 7), (6, 1)

**Solution:**
Centroid = ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)
= ((2+4+6)/3, (3+7+1)/3)
= (12/3, 11/3)
= (4, 11/3)

**Answer:** (4, 11/3)

## Problem 18: Concurrent Lines
**Question:** For what value of k are lines x + 2y = 3, 2x - y = 5, and kx + y = 7 concurrent?

**Solution:**
Find intersection of first two:
From first: x = 3 - 2y
Substitute: 2(3 - 2y) - y = 5
6 - 4y - y = 5
y = 1/5, x = 13/5

For concurrency: k(13/5) + 1/5 = 7
13k/5 = 7 - 1/5 = 34/5
k = 34/13

**Answer:** k = 34/13

## Problem 19: Two-Point Form
**Question:** Find equation of line passing through (-1, 2) and (3, -4)

**Solution:**
(y - y₁)/(y₂ - y₁) = (x - x₁)/(x₂ - x₁)
(y - 2)/(-4 - 2) = (x - (-1))/(3 - (-1))
(y - 2)/(-6) = (x + 1)/4
4(y - 2) = -6(x + 1)
4y - 8 = -6x - 6
6x + 4y - 2 = 0
3x + 2y - 1 = 0

**Answer:** 3x + 2y - 1 = 0

## Problem 20: Distance Between Parallel Lines
**Question:** Find distance between parallel lines 3x + 4y = 5 and 3x + 4y = 15

**Solution:**
d = |c₂ - c₁|/√(a² + b²)
= |15 - 5|/√(9 + 16)
= 10/√25
= 10/5 = 2

**Answer:** 2
